# 🧠 DSA Mastery

A premium, modern web application dedicated entirely to mastering Data Structures & Algorithms. Features a personalized roadmap, multi-language code solutions, spaced repetition, quizzes, flashcards, a coding workspace, and comprehensive progress analytics.

## ✨ Features

- **📊 Dashboard** — Overall progress, current phase, daily streak, study calendar, heatmap, progress charts
- **🗺️ Learning Roadmap** — 30 phases from beginner to advanced, customizable start/target dates, hours/day, days/week
- **📝 Topic Pages** — Concept explanations, complexity analysis, pseudocode, dry runs, edge cases, common mistakes, best practices
- **💻 Multi-Language Support** — Java, C++, Python, C, JavaScript, Go, C#, Kotlin, Rust
- **🎯 Coding Problems** — Curated LeetCode problems with hints, optimal approaches, and solutions in 9 languages
- **📅 Daily/Weekly/Monthly Planners** — Auto-generated study schedule based on your preferences
- **🔄 Spaced Repetition** — Revision system with 1/3/7/15/30/60 day intervals
- **📔 Notes System** — Create, edit, bookmark, and export notes with code snippets
- **🃏 Flashcards** — 100+ flashcards for definitions, algorithms, complexity, and tricks
- **🧠 Quiz System** — MCQs, code output, complexity, and debugging questions
- **⌨️ Coding Workspace** — Built-in editor with multi-language support and saved solutions
- **📈 Progress Analytics** — Charts for daily/weekly/monthly learning, topic completion, difficulty distribution
- **🔍 Global Search** — Search topics, problems, patterns, and tags
- **🔖 Bookmarks** — Bookmark topics, problems, notes, and algorithms
- **🎨 Premium UI** — Dark/light mode, glassmorphism, smooth animations, responsive design
- **📱 PWA** — Offline support, installable on mobile devices

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + Glassmorphism
- **Backend:** Supabase (Auth + PostgreSQL)
- **State:** Zustand with localStorage persistence
- **Charts:** Recharts
- **Icons:** Lucide React

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🔧 Supabase Setup

1. Create a new project at [supabase.com](https://supabase.com)
2. Copy `.env.example` to `.env` and fill in your Supabase URL and anon key
3. Run the SQL schema in `supabase/schema.sql` in your Supabase SQL editor
4. The app works offline-first with localStorage, syncing to Supabase when configured
